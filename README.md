# 🐛 Червячные Войны 2D (Worms Battle) — Мега-Обновление

Пошаговая артиллерийская тактическая 2D-игра по мотивам легендарных Worms.
Команды червяков (🔴 Красные, 🔵 Синие, 🟢 Зелёные, 🟡 Жёлтые) сражаются на процедурно генерируемом острове с разрушаемым ландшафтом, баллистической физикой, ветром, ящиками с бонусами и мощным арсеналом супероружия.

---

## 🚀 Как запустить локально (офлайн)

1. **Самый быстрый способ**: Просто откройте файл `index.html` двойным кликом в браузере.
2. **Через батник Windows**: Запустите `start.bat`. Он поднимет локальный сервер и автоматически откроет страницу в браузере.
3. **Через Python**:
   ```bash
   python server.py
   ```

## 🎮 Режимы игры и Команды

- ⚔️ **Игрок против Игрока (Hotseat)**: Игра в компании за одним компьютером или экраном.
- 🤖 **Против Компьютера (AI Боты)**: Компьютерные соперники целятся, учитывают поправку на ветер и применяют весь арсенал.
- **2, 3 или 4 Команды**:
  - 🔴 **Красные штурмовики** (в красных банданах)
  - 🔵 **Синие десантники** (в военных касках со звездой)
  - 🟢 **Зелёный спецназ** (в коммандо-беретах с эмблемой)
  - 🟡 **Жёлтая гвардия** (в королевских коронах с рубинами)
- **От 2 до 6 червяков в каждой команде** (до 24 червей на одном огромном острове!).

## 🦖 Бонус: Мега-Гигант (Ящики припасов)

- На поле боя с парашютом периодически падают ящики припасов:
  - 🦖 **Ящик Мутации**: Превращает червяка в **Мега-Гиганта** с **400 HP**! Гигант получает двойной размер, золотую ауру, тяжелую поступь и колоссальную устойчивость к взрывным волнам.
  - ❤️ **Аптечка**: Восстанавливает +60 HP.
  - 📦 **Ящик с боеприпасами**: Пополняет боекомплект ограниченного оружия для всей команды!

## 💣 Полный арсенал оружия (15 видов с лимитами боезапаса)

1. 🚀 **Базука (Клавиша 1, ∞)**: Классическая ракета с детонацией при контакте. Сносится ветром!
2. 💣 **Граната (Клавиша 2, x5)**: 3-секундный таймер. Прыгает по холмам и оврагам.
3. 💥 **Кластерная бомба (Клавиша 3, x3)**: При подрыве разлетается на 5 осколочных бомб.
4. 🔫 **Дробовик (Клавиша 4, ∞)**: 2 выстрела за ход! Пробивает точечные бреши и сталкивает врагов в море.
5. 🧨 **Динамит (Клавиша 5, x2)**: Кладется под ноги. 5-секундный фитиль, 75 ед. урона и глубокий кратер.
6. 🥊 **Бейсбольная бита (Клавиша 6, x2)**: Ближний бой. Запускает врага через всю карту в воду («Хоум-ран!»).
7. ✝️ **Святая граната (Клавиша 7, x1)**: Легендарное оружие! Перед взрывом звучит хор «Аллилуйя!», после чего следует взрыв колоссальной мощности (115 урона)!
8. 🫏 **Мраморный осёл (Клавиша 8, x1)**: Культовое супероружие! С неба падает гигантская каменная статуя осла, которая с громким ржанием «И-а!» многократно пробивает остров насквозь в пучину океана!
9. ⚡ **Электрошок (Клавиша 9, x3)**: Высоковольтный электрический разряд, бьющий током на 48 урона с отбрасыванием.
10. 🔦 **Лазерный бур (Клавиша 0, x3)**: Мощный индустриальный лазер, прожигающий сквозной тоннель сквозь скалы и врагов.
11. 🌀 **Аннигиляторная пушка (Склад, x1)**: Заряжает сгусток чистой антиматерии, аннигилирующий породу и противников (100 урона).
12. ☀️ **Луч солнца (Склад, x1)**: Орбитальный столп небесного солнечного пламени, прожигающий остров до самого дна.
13. ✈️ **Авиаудар (Склад, x1)**: Истребитель сбрасывает 5 авиабомб в выбранную точку.
14. 🛩️ **Ковровый удар (Склад, x1)**: Тяжелый бомбардировщик ковровой дорожкой сбрасывает 10 кассетных бомб.
15. 🛸 **Телепорт (Склад, x2)**: Мгновенное безопасное перемещение в любую точку острова.

## 🕹️ Управление

| Действие | Клавиши / Мышь |
|---|---|
| **Ходить влево / вправо** | `A` / `D` или стрелки `←` / `→` (или сенсорные кнопки ◀ / ▶) |
| **Прыжок вперед** | `W` / стрелка `↑` / `Enter` (или сенсорная кнопка 🦘) |
| **Сальто назад** | `Backspace` или `Shift + ↑` |
| **Прицеливание** | Курсор мыши / сенсорный тап по экрану |
| **Зарядка и выстрел** | Удерживайте `Пробел` (или кнопку 🔥) для силы броска |
| **Оружие ближнего боя / бур** | Нажатие `Пробел` / кнопка 🔥 |
| **Быстрый выбор оружия** | Клавиши `1` – `9`, `0` |
| **Оружейный склад (инвентарь)** | Клавиша `Q` или **Правый клик мыши** |
| **Смена активного червяка** | `Tab` (до совершения выстрела) |
| **Супероружие по клику** | Клик мышью в точку на карте (Авиаудар, Осёл, Ковер, Луч солнца, Телепорт) |
| **Масштаб (Зум)** | Колесико мыши |
