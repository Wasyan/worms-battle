# 🐛 Червячные Войны 2D (Worms Battle)

Пошаговая артиллерийская тактическая 2D-игра по мотивам легендарных Worms.
Две команды червяков (Красные и Синие) сражаются на процедурно генерируемом острове с разрушаемым ландшафтом, баллистической физикой, ветром и разнообразным арсеналом вооружения.

---

## 🚀 Как запустить игру

1. **Самый быстрый способ**: Просто откройте файл `index.html` двойным кликом в любом современном браузере (Chrome, Edge, Firefox, Opera).
2. **Через батник Windows**: Запустите `start.bat`. Он поднимет локальный сервер и автоматически откроет страницу в браузере.
3. **Через Python**:
   ```bash
   python server.py
   ```

---

## 🎮 Режимы игры

- ⚔️ **2 Игрока (Hotseat)**: Игра вдвоем на одной клавиатуре и мыши, червяки ходят строго по очереди.
- 🤖 **Против Компьютера (AI Бот)**: Сражение с умным ботом, который оценивает дистанцию, учитывает ветер, баллистику и использует базуки, гранаты, биты и авиаудары.
- **Размер команд**: 2 на 2 (быстрая дуэль), 3 на 3 (классика) или 4 на 4 (тотальная война).

## 🕹️ Управление

| Действие | Клавиши / Мышь |
|---|---|
| **Ходить влево / вправо** | `A` / `D` или стрелки `←` / `→` |
| **Прыжок вперед** | `W` / стрелка `↑` / `Enter` |
| **Высокое сальто назад** | `Backspace` или `Shift + ↑` |
| **Прицеливание** | Движение курсора мыши вокруг червяка |
| **Заряд силы и выстрел** | Удерживайте `Пробел` (чем дольше, тем дальше летит) и отпустите для пуска |
| **Выстрел / удар мгновенным оружием** | Одиночное нажатие `Пробел` (Дробовик, Бита, Динамит) |
| **Быстрый выбор оружия** | Клавиши цифр `1` – `8` |
| **Оружейный склад (инвентарь)** | Клавиша `Q` или **Правый клик мыши** |
| **Смена активного червяка** | Клавиша `Tab` (до совершения выстрела) |
| **Авиаудар / Телепорт** | Клик **Левой кнопкой мыши** в желаемую точку карты |
| **Масштаб камеры (Зум)** | Колесико мыши |
| **Справка / Пауза** | Клавиша `Esc` или кнопка `?` |
| **Звук** | Кнопка 🔊 в правом верхнем углу |

## 💣 Арсенал оружия

1. 🚀 **Базука (Клавиша 1)**: Ракетница с взрывом по контакту. Сильно подвержена влиянию бокового ветра!
2. 💣 **Граната (Клавиша 2)**: 3-секундный таймер. Прыгает по холмам и скатам, идеальна для заброса за укрытия.
3. 💥 **Кластерная бомба (Клавиша 3)**: При взрыве распадается на 5 осколочных зарядов, накрывающих большую площадь.
4. 🔫 **Дробовик (Клавиша 4)**: 2 выстрела за ход! Пробивает точечные отверстия в грунте и отталкивает червяков прямо в воду.
5. 🧨 **Динамит (Клавиша 5)**: Сбрасывается под ноги. Таймер 5 секунд (успейте убежать!). Огромный радиус и 75 ед. урона!
6. 🥊 **Бейсбольная бита (Клавиша 6)**: Оружие ближнего боя. Червяк отправляется в мощный полет далеко в океан!
7. ✈️ **Авиаудар (Клавиша 7)**: Укажите мышкой точку: истребитель пролетит над островом и сбросит 5 бомб.
8. 🛸 **Телепорт (Клавиша 8)**: Мгновенное перемещение в любую безопасную точку острова (завершает ход).

## ⚙️ Физика и особенности движка

- **Полностью разрушаемый ландшафт**: Каждый взрыв физически вырезает кратеры в пиксельном массиве и текстуре земли, обнажая свежую траву.
- **Вода и утопление**: Внизу карты плещется океан. Червяк, упавший в воду, моментально тонет (с анимацией нимба и брызг).
- **Динамический ветер**: Сила и направление ветра меняются каждый ход, влияя на полет ракет.
- **Встроенный процедурный звук (Web Audio API)**: Все звуковые эффекты (взрывы, выстрелы, свист ветра, писк червяков, плеск воды) генерируются в реальном времени синтезатором, без внешних файлов.
- **Фаза отхода**: После атаки у червяка есть 3 секунды, чтобы спрыгнуть в укрытие до передачи хода.
